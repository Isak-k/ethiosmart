## Color Coding System

### Correct Answer
- 🟢 Green border and background
- ✓ Icon with "Correct" badge
- Green feedback box

### Incorrect Answer
- 🔴 Red border and background
- ✗ Icon with "Incorrect" badge
- Red feedback box

### Skipped Answer
- ⚪ Gray border and background
- ⏱ Clock icon with "Skipped" badge
- No feedback shown

### Pending (Essay)
- 🟡 Amber border and background
- ⚠ Alert icon with "Pending Review" badge
- Amber info box

### Graded (Essay)
- 🟢/🔴 Green or Red based on score
- Icon with "Graded" badge
- Shows score and comment

## Key Features in Review UI

1. **Color-Coded Status**
   - Instant visual feedback on correctness
   - Easy identification of weak areas

2. **Complete Answer Display**
   - Shows exactly what student entered
   - Formatted properly (essays preserve line breaks)

3. **Correct Answer Reference**
   - Shown for all question types (except essays)
   - Multiple acceptable answers for short answers
   - Helps student learn from mistakes

4. **Feedback Messages**
   - Specific feedback for correct/incorrect
   - Different messages for each question type
   - Encouraging for correct, constructive for incorrect

5. **Explanations**
   - Educational context from instructor
   - Helps understanding, not just grading
   - Supports self-directed learning

6. **Essay-Specific Features**
   - Pending status while awaiting grading
   - Grader comments when complete
   - Rubric scores
   - Full essay text with proper formatting

7. **Marks Display**
   - Shows earned marks vs. total
   - Visible only for answered questions
   - Helpful for understanding scoring

## Responsive Design

- **Desktop**: Full layout with all elements visible
- **Tablet**: Adjusted spacing, stackable elements
- **Mobile**: Single column, swipe-friendly badges, readable text

## Interactive Elements

- All text is selectable (for copying answers)
- Badges are non-interactive (informational only)
- Smooth scrolling between questions
- Back button returns to exam list
- Export CSV button downloads results
