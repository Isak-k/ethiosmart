# ExamPro: API Documentation — Question Type System

This document provides the public API for the new mixed-type question system.
Use it when building new components, authoring tests, or writing migration
scripts.

---

## 1. Type Definitions

**Location:** `src/integrations/firebase/types.ts` (unions + discriminating guards)
**Location:** `src/integrations/firebase/question-types.ts` (older duplicate, kept for compatibility;
prefer the `types.ts` exports).

### 1.1 Discriminated Union — `Question`

```ts
export type QuestionType = "mcq" | "true-false" | "short-answer" | "essay";

export interface BaseQuestion {
  questionId: string;
  examId: string;
  questionType: QuestionType;  // discriminant
  questionText: string;
  marks: number;
  orderIndex: number;
  feedbackType: "instant" | "hidden";
  explanation?: string;
  imageUrl?: string;
  imageDisplayMode?: "inline" | "background" | "main";
  difficulty?: "easy" | "medium" | "hard";
  tags?: string[];
  createdAt?: Timestamp | Date | null;
  updatedAt?: Timestamp | Date | null;
}

export interface MCQQuestion extends BaseQuestion {
  questionType: "mcq";
  options: string[];                         // length ∈ [2, 6]
  correctOptionIndex: number;                // length ∈ [0, options.length)
}

export interface TrueFalseQuestion extends BaseQuestion {
  questionType: "true-false";
  correctAnswer: boolean;
}

export interface ShortAnswerQuestion extends BaseQuestion {
  questionType: "short-answer";
  correctAnswers: string[];                  // non-empty
  caseSensitive?: boolean;                   // default false
  requireExactMatch?: boolean;               // default true
}

export interface EssayQuestion extends BaseQuestion {
  questionType: "essay";
  minWords?: number;
  maxWords?: number;
  rubric?: EssayRubric;                      // see types.ts
}

export type Question =
  | MCQQuestion
  | TrueFalseQuestion
  | ShortAnswerQuestion
  | EssayQuestion;
```

### 1.2 Type Guards (use these before accessing type-specific fields)

All live in `src/integrations/firebase/types.ts`:

```ts
export function isMCQQuestion(q: any): q is MCQQuestion;
export function isTrueFalseQuestion(q: any): q is TrueFalseQuestion;
export function isShortAnswerQuestion(q: any): q is ShortAnswerQuestion;
export function isEssayQuestion(q: any): q is EssayQuestion;
```

Properties:
- **Mutually exclusive** — for any well-formed `Question`, exactly one guard
  returns `true`. (Verified by PBT in Phase 8 test suite.)
- **Safe on raw Firestore data** — each guard checks `question.questionType`
  plus structural existence of the required field.

Pattern:

```ts
import { isMCQQuestion, isEssayQuestion } from "@/integrations/firebase/types";

if (isMCQQuestion(q)) {
  // TS narrows q → MCQQuestion.  q.options and q.correctOptionIndex are safe.
} else if (isEssayQuestion(q)) {
  // TS narrows q → EssayQuestion.  q.minWords, q.maxWords, q.rubric are safe.
}
```

## 2. Validation

**Location:** `src/lib/question-validator.ts`

```ts
export interface ValidationResult {
  valid: boolean;
  errors: string[];                    // human-readable, i18n-capable keys
  warnings?: string[];
}

export function validateQuestionBeforeSave(
  input: NewQuestionInput,              // discriminated union in src/lib/validations.ts
  t?: TFunction
): ValidationResult;

export function formatValidationErrors(errors: string[]): string;
```

Each type is validated by its own Zod schema (`getNewQuestionSchema(...)` in
`src/lib/validations.ts`). For example:

| Type | Key validators |
|---|---|
| MCQ | `options.length ∈ [2,6]`, `correctOptionIndex ∈ [0, options.length)`, no option is empty |
| True/False | `correctAnswer: boolean` is required |
| Short Answer | `correctAnswers` non-empty, every entry `trim().length > 0` |
| Essay | `minWords >= 0`, `maxWords >= 0`, `minWords <= maxWords` when both set; rubric total == question.marks when rubric present |

Also: `validateImagePayload` and `validateImageSize` in
`src/lib/image-handler.ts`.

## 3. Evaluation / Grading

**Location:** `src/lib/question-evaluation.ts`

```ts
export interface EvaluationResult {
  isCorrect: boolean;
  earnedMarks: number;
  totalMarks: number;
  feedback?: string;                        // user-facing
  explanation?: string;                     // from question.explanation
  details?: EssayEvaluationDetails | ...;
}

// Per-type evaluators — throw TypeError if wrong questionType.
export function evaluateMCQ(question: MCQQuestion, answer: number | null): EvaluationResult;
export function evaluateTrueFalse(question: TrueFalseQuestion, answer: boolean | null): EvaluationResult;
export function evaluateShortAnswer(question: ShortAnswerQuestion, answer: string | null): EvaluationResult;
export function evaluateEssay(question: EssayQuestion, answer: string | null): EvaluationResult;

// Dispatcher — pick per-type evaluator by `question.questionType`
export function evaluateQuestion(question: Question, answer: any): EvaluationResult;

// Batch: answer Map keyed by question.questionId.
export function batchEvaluateAnswers(
  questions: Question[],
  answers: Map<string, any>
): EvaluationResult[];

// Aggregate results into score breakdown.
export function calculateExamScore(
  results: EvaluationResult[],
  passPercentage: number
): {
  totalMarks: number;
  maxMarks: number;
  percentage: number;
  passStatus: "pass" | "fail";
  correctCount: number;
  incorrectCount: number;
  skippedCount: number;
  pendingCount: number;
};
```

Semantics summary:

| Type | `isCorrect` trigger | `earnedMarks` range |
|---|---|---|
| MCQ | `answer === question.correctOptionIndex` | 0 or `marks` |
| True/False | `answer === question.correctAnswer` | 0 or `marks` |
| Short Answer | any entry in `correctAnswers` matches (with/without case sensitivity + trimming) | 0 or `marks` |
| Essay | Always `false` — always **pending manual grading**; essay words OK ⇒ `pending`, else `"too short"` / `"too long"` message | 0 (until manual grade is saved) |

## 4. Legacy Migration Utilities

**Location:** `src/lib/question-migration.ts` (loaded automatically by
`getExamQuestions` in `src/lib/firebase-questions.ts`).

```ts
export function isLegacyQuestion(q: any): boolean;        // has options + correctOptionIndex but NO questionType
export function migrateLegacyQuestion(q: LegacyQuestion | any): Question;
export function migrateLegacyQuestions(qs: any[]): Question[];

// Adds questionType (defaults "mcq") when missing; does NOT overwrite explicit questionType
export function ensureQuestionType(q: any): Question;

export function getQuestionType(q: any): string;          // safe accessor, never returns undefined

export function validateMigration(
  original: LegacyQuestion, migrated: Question
): { valid: boolean; errors: string[] };
```

Rules:
1. Legacy question = MCQ semantics; the migration simply sets
   `question.questionType = "mcq"` (no other fields are changed).
2. Explicit `questionType` is never overwritten.
3. Auto-applied on read in `getExamQuestions` — your UI code never needs to
   touch legacy payloads.

## 6. Components

### 6.1 Question Renderer (Exam/Practice/Results)

```tsx

<QuestionRenderer
  questionNumber={1}
  question={question}           // Question union
  selectedAnswer={myMap.get(question.questionId) ?? null}
  correctAnswer={/* only in results view */}
  isSubmitted={isSubmitted}
  onAnswerChange={(ans: string | number | boolean | null) => ...}
  marks={question.marks}
  mode="exam"                   // "exam" or "practice"

```

Supported shapes:
- MCQ → `<option button grid>`
- True/False → 2 large buttons (True / False)
- Short Answer → single-line `<Input>`
- Essay → multi-line `<Textarea>` + live word counter + (optional) min/max guidance

Practice mode engine: `src/lib/practice-mode-engine.ts`

Both expose `selectOption` / `next` / `prev` / `jumpTo` and persist answers into

`batchEvaluateAnswers`.

`src/pages/GradeEssays.tsx` → `recomputeAndUpdateAttemptScore`.

## 8. Stability Notes

- The union `Question` is open (new types can be added later). Before adding a
  5th type, ensure all switch statements and QuestionRenderer have exhaustive
  `default: assertNever(q)` branches.
- Do **not** compare against literal `== "mcq"` strings in new code — use the
  exported type guards (`isMCQQuestion` / `isEssayQuestion` / ...) so TypeScript
  narrows correctly.
- Use `evaluateQuestion()` dispatcher instead of calling
  `evaluateMCQ/.../evaluateEssay` directly — it ensures the right evaluator
  always runs for the actual runtime `questionType`.
