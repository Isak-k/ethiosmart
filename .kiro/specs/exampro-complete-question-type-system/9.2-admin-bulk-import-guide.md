# ExamPro: Admin Guide — Bulk Import of Mixed-Type Questions

This guide is for admin/super-admin users preparing large question banks. It
covers:

- Built-in **Bulk Import Dialog** (`BulkImportQuestions.tsx`)
- **PDF → AI → MCQ** generation
- **Text-format import** (MCQ parser — the natively supported path today)
- Recommended **CSV / JSON patterns** you can pre-process before import
- Validation + preview workflow

**Entry file:** `src/components/exam/BulkImportQuestions.tsx`
**Parser:** `src/lib/question-parser.ts`
**Validators:** `src/lib/question-validator.ts`, `src/lib/import-validator.ts`
**Batch save:** `saveQuestionsBatch` in `src/lib/firebase-exams.ts`

---

## 1. Import Methods

| Method | Question types supported | Steps |
|---|---|---|
| **1a. Paste raw text** | MCQ (natively) *1 | Paste → Analyze → Preview → Import |
| **1b. Upload PDF** | MCQ only (via AI) | Upload PDF → Extract text → Generate MCQs with Gemini API → Preview → Import |
| **1c. Custom CSV / JSON → Text pre-process** | Any *2 | Convert CSV → `parseQuestions` format (or save via admin script) → Paste into dialog → Import |

*1 The parser can be extended for TF / SA / Essay; today `parseQuestions` returns
MCQ-shaped `ParsedQuestion`. Use method 1c when you need to mix in non-MCQ
questions.*

*2 See §3 "Preparing Mixed-Type CSV".*

## 2. Raw-Text Format (MCQ — native)

`parseQuestions` in `src/lib/question-parser.ts#L31` recognizes this flexible
syntax:

```
1. What is the capital of France?
A. London
B. Paris *
C. Rome
D. Berlin
Answer: B
Explanation: Paris is the capital and largest city of France.

2. 2 + 2 equals 5?
A. True
B. False *
Answer: B
```

Rules:

- **Question start:** `1.`, `1)`, `1-`, `1 `, `Q1.`, `Question 1:` are all valid.
- **Options:** `A.`, `(A)`, `a)`, `A-`, or `A `.
- **Correct answer:** Either append `*` at the end of the correct option line
  *or* add an `Answer:` / `Ans:` / `Correct:` line after the options.
- **Explanation:** `Explanation:` / `Exp:` / `Reason:` after options.

If you provide both a `*` marker and an `Answer:` line, `Answer:` wins.

## 3. Preparing Mixed-Type CSV / JSON

If you need to bulk-import **True/False, Short Answer, or Essay** questions,
convert them into the `NewQuestionInput` union used by QuestionTypeForm. The
easiest bulk pattern is JSON Lines.

### 3.1 JSON Lines Schema

Each line is a valid `NewQuestionInput` object — for schema, see
`src/lib/validations.ts` and `getNewQuestionSchema`.

```jsonl
{"questionType":"mcq","questionText":"2 + 2?","marks":1,"options":["3","4","5","6"],"correctOptionIndex":1}
{"questionType":"true-false","questionText":"Water boils at 100 C at sea level.","marks":1,"correctAnswer":true}
{"questionType":"short-answer","questionText":"Chemical symbol for gold?","marks":2,"correctAnswers":["Au","AU","au"],"caseSensitive":false,"requireExactMatch":true}
{"questionType":"essay","questionText":"Describe the water cycle.","marks":10,"minWords":50,"maxWords":400}
```

You can paste the same contents into the Bulk Import dialog's "Paste text" tab
using a trivial admin script that converts each line to a UI call. For highest
throughput, call `saveQuestionsBatch(examId, questions)` directly — implemented
in `src/lib/firebase-exams.ts`.

### 3.2 CSV Template (mixed types)

Use the following headers. Empty fields are ignored for types that don't need
them.

```csv
questionType,orderIndex,questionText,marks,options,correctOptionIndex,correctAnswer,correctAnswers,caseSensitive,minWords,maxWords
mcq,1,"What is 2+2?",1,"""[""3"",""4"",""5"",""6""]""",1,,,,,
true-false,2,"The sky is blue.",1,,,true,,,,
short-answer,3,"Capital of Japan?",2,,,"[""Tokyo"",""Tokyo, Japan""]",false,,
essay,4,"Discuss Newton's laws.",10,,,,,,100,1000
```

Notes:

- `options` and `correctAnswers` are JSON-encoded strings so commas inside the
  array don't break the CSV columns.
- `caseSensitive` defaults to `false` when blank.
- `requireExactMatch` can be added as a column for Short Answer (defaults
  `true`).

### 3.3 Validation Pipeline

For any bulk payload, run it through:

```
import-validator.validateImportRows(rows)
  → per-type structural checks
question-validator.validateQuestionBeforeSave(q, t)
  → Zod schema check
saveQuestionsBatch(examId, rows)
  → Firestore writes with generated questionId/orderIndex
```

Existing tests: 16 tests in `src/lib/__tests__/import-validator.test.ts`
and 24 tests in `src/lib/question-validator.test.ts`. See Phase 8 test suite.

## 4. PDF → AI MCQ Generation

For study material you already have, the Bulk Import dialog offers an AI
workflow:

1. Upload a PDF (image-based PDFs will fail with a friendly message — we
   extract text only).
2. Provide your Google **Gemini API key** (stored in-page only; never sent to
   ExamPro servers).
3. Choose how many MCQs to generate (default 20).
4. Click **Generate**.

The prompt in `BulkImportQuestions.tsx#L109` enforces:

- Exactly N questions, 4 options each, exactly one correct (marked with `*`).
- Only content from inside the PDF (no outside knowledge).
- An `Explanation:` line per question.

Generated questions are shown in the **Preview** tab; check **Count**,
**Errors**, then click **Import**.

## 5. Import Preview + Go / No-Go Checklist

Before clicking **Import**, confirm in the Preview pane:

- [ ] Count matches what you expected.
- [ ] No validation errors are listed (`errors: []`).
- [ ] MCQ correct indices are set (you'll see `*` next to correct answers).
- [ ] Short Answer has ≥1 accepted answer.
- [ ] Essay `marks` match your rubric (essays default to 0 auto-grade; manual
      grading happens in GradeEssays).

After import, open **Edit Exam** to verify the Badge row shows each question
type (Phase 7 feature — `src/pages/EditExam.tsx#L137`).

## 6. Troubleshooting

| Symptom | Likely cause | Fix |
|---|---|---|
| "No correct answer detected" for MCQ | No `*` and no `Answer:` line | Either append `*` to the correct option, or add `Answer: B` below options. |
| Missing 2+ options error | Only one option parsed | Make sure each option starts with its own `A.` / `B.` / etc. on a new line |
| PDF → "Could not extract enough text" | Image-based or encrypted PDF | Convert PDF to text, or paste raw text |
| "Firebase quota exceeded" | High write volume | Split large banks into batches (<500 questions / batch) |
| Short Answer "case mismatch" in test | Student expects case-insensitive match but `caseSensitive: true` | Adjust per question in QuestionTypeForm |

---

## 7. Rollback

Since BulkImport writes via `saveQuestionsBatch`, to revert a bad import:

1. Open Edit Exam for the affected exam.
2. Delete the newly imported questions by index (they have the highest orderIndex
   values).
3. Save Exam. For truly large rollbacks, delete the exam and restore the
   Firestore backup if available.
